## How it works

`render.py` draws the front page (1024x1024 PNG) with PIL — navy header naming the day, three illustrated hero cards, a dotted world map with numbered pins, flag cards, a UTC timeline, the full 34-story list, and a DATE CHECK box. The finished image ships as `entry.png`; `main.py` (standard library only) copies it to the output directory at grading time.
